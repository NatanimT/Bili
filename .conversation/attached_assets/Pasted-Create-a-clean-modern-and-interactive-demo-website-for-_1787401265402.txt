Create a clean, modern, and interactive demo website for a female personal trainer and weight loss coach. 

**CONTEXT:**
She is a personal trainer who lost significant weight herself and now helps others achieve their fitness goals through in-person training. The website should tell her transformation story and convert visitors into clients.

**TECHNICAL REQUIREMENTS:**
- Use ONLY free and open-source libraries
- HTML5, CSS3, and vanilla JavaScript
- Use Tailwind CSS (via CDN) for styling
- Use Font Awesome or Lucide icons (via CDN)
- Use Google Fonts (suggest a modern, clean font pair)
- Use AOS (Animate On Scroll) library for scroll animations
- Make it fully responsive (mobile-first approach)
- Single-page application with smooth scroll navigation

**PAGES/SECTIONS NEEDED:**

1. **HERO SECTION:**
   - Full-width header with a placeholder for her photo
   - Headline: "From [X] lbs to Fit & Strong - I'll Help You Do The Same"

2. **TRANSFORMATION STORY (About Section):**
   - Two-column layout (image left, text right)
   - Before/After image placeholders side by side

   - Stats counters (e.g., "50+ lbs Lost", "100+ Clients Transformed", "5 Years Experience")
   - Animated counter when scrolled into view

3. **SERVICES SECTION:**
   - Three service cards:
     a) "1-on-1 Personal Training" - In-person sessions
     b) "Nutrition Coaching" - Meal plans & calorie guidance
     c) "Transformation Program" - 12-week complete package
   - Each card: icon, title, description, price range, "Learn More" button
   - Hover effects on cards (lift up shadow)

4. **CLIENT RESULTS SECTION:**
   - Grid layout for before/after client photos (use placeholders)
   - Testimonial carousel/slider with:
     - Client photo placeholder
     - Star rating (5 stars)
     - Quote/testimonial text
     - Client name and results achieved

5. **WHY CHOOSE ME SECTION:**
   - 4-6 feature boxes with icons:
     - "Certified Personal Trainer"
     - "Customized Workout Plans"
     - "Nutrition & Meal Planning"
     - "Weekly Progress Tracking"
     - "Ongoing Support & Motivation"
     - "Proven Results"
   - Icons should animate on hover

6. **CONTACT/BOOKING SECTION:**
   - Two-column layout
   - Left side: Contact info (email, phone, location, social media icons)
   - Right side: Simple contact form with fields:
     - Name
     - Email
     - Phone
     - Goal (dropdown: Weight Loss, Muscle Gain, General Fitness, Other)
     - Message
     - Submit button
   - Form validation with JavaScript

7. **FOOTER:**
   - Copyright text
   - Social media links (Instagram, Facebook, TikTok, YouTube)
   - Quick navigation links
   - Email signup for newsletter (simple input + button)

**INTERACTIVE FEATURES:**
- Smooth scroll navigation when clicking menu items
- Mobile hamburger menu with slide-in animation
- Scroll-to-top button (appears after scrolling down)
- Lazy loading for images
- Form submission with success message (no backend needed, just frontend demo)
- Counter animation when stats section comes into view
- Testimonial slider with next/prev buttons and dots
- Hover effects on all buttons and cards
- Parallax effect on hero section (subtle)

**DESIGN SPECIFICATIONS:**
- Color scheme: 
  - Primary: Energetic color (coral, teal, or purple - your choice)
  - Secondary: Complementary color
  - Accent: Gold or bright color for CTAs
  - Backgrounds: White and light gray alternating sections
  - Text: Dark gray/black for readability
- Typography: 
  - Headings: Bold, modern sans-serif (e.g., Poppins, Montserrat)

- Spacing: Generous whitespace between sections
- Border radius: Rounded corners (8-12px) on cards and buttons
- Shadows: Subtle box shadows on cards, stronger on hover
